# Colombia — An Epic History

A five-minute motion-graphics film about the history of Colombia, from El Dorado to 2026, with an original orchestral score generated in the browser.

**Watch it:** https://jmariasm1.github.io/ColombiaHistory/

- Everything is drawn live on an HTML canvas; the music is synthesized with the Web Audio API when the page loads (about 45 seconds).
- Best viewed in Chrome or Edge, in fullscreen (F), with headphones.
- "Record video" plays the film once in real time and saves it as an MP4.
- Add `?t=SECONDS` to the address to open a still of any moment, e.g. `?t=62`.
